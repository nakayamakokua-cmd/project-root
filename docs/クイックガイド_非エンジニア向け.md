# クイックガイド（非エンジニア向け）

このプロジェクトで「音声 → 解析 → スプレッドシート反映」まで実行するための、最短の手順です。

## 1. 事前準備（初回のみ）
- Googleの認証ファイルを置く（どちらかでOK）
  - `config/credentials.json` または プロジェクト直下の `credentials.json`
- Python環境がある状態を想定（仮想環境は任意）

## 2. 単発で試す
1) 文字起こし → 解析 → スプレッドシート追記（失敗時はCSV/NDJSONへ退避）

```
make run-all
```

2) スプレッドシートが書けなかった場合（ネット切断など）
- 退避ファイル: `Outputs/csv/append_fallback.csv` と `Outputs/csv/append_fallback.ndjson`
- 後から再送する: `make resend-fallback`

## 3. まとめて処理する（フォルダ監視）
1) 音声ファイルを `Audio/inbox` に置く
2) 監視実行

```
make watch
```

3) 結果の見方
- 成功: `Audio/processed` に移動
- 失敗: `Audio/error` に移動 + `<ファイル名>.err.txt` に理由
- ログ: `logs/watcher.log`

## 3.1 自動実行モード（放っておくと自動で回る）
- 始める: `make auto-start`
  - 30秒ごとに `Audio/inbox` を見て、あれば自動実行します
  - 間隔を変える: `POLL_INTERVAL=15 make auto-start`
- 止める: `make auto-stop`
- 状態確認: `make auto-status`
- ログ: `logs/auto_runner.log`

## 4. 困ったときは
- 認証が通らない → `credentials.json` が正しい場所にあるか確認。初回はブラウザで許可画面が出ます。
- ネット不安定 → 自動でCSV/NDJSONに退避。復旧後に `make resend-fallback`
- 設定不足 → `config/settings.json` の `sheets.spreadsheet_id` と `sheets.sheet_name` を確認（無ければ `google.*` でも可）
