# 製品コンテキスト（要約）
- 目的: 通話ごとの評価自動化、NG要因可視化、現場コーチング高速化。
- 音声→Gemini文字起こし→Gemini解析（分岐/NG/指標/根拠/コメント）→Sheets/CSV→(将来)ChromaDB→Reactダッシュボード。
- 最重要ルール:
  - 分岐は「最初の顧客反応」で固定 (#3-1/3-2/3-3/3-4, 例外：#2直→日程=メダパニ)。
  - 最終NGは「終話ウィンドウ（60秒目安）内の最後の候補」優先→なければ確定度でタイブレーク。
  - NG出力は大分類/中分類とも**日本語**。会話内に複数出た場合は**発話順**で `ng_reason_chain` に**カンマ区切り**で格納。
  - トークスクリプト適合度: E1〜E4(+G)の意味一致で採点、≥70で合格。
- フォールバック:
  - Sheetsが落ちたらOutputs/csv/へ追記。後でバッチでSheets同期。
 
ユーザープロファイル（重要）:
- 日本語話者。非エンジニアの利用者を想定。
- すべての変更・案内に「非エンジニア向けの簡潔な説明」を併記すること。
